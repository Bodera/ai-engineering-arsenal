# Knowledge Base

The concepts and foundational knowledge behind the guidelines and frameworks in this repository.

This is where I consolidate things I am learning, studying, revisiting, or connecting to other areas of engineering.

Possible topics include:

- logical reasoning
- graph theory and graph-based thinking
- programming principles
- software architecture
- algorithms and data structures
- networking
- distributed systems
- operating systems and Linux
- developer tooling
- AI and machine learning concepts

The goal is not to build an encyclopedia. The goal is to build **usable understanding**.

Whenever possible, entries should connect theory to engineering practice, experiments, or concrete examples.
