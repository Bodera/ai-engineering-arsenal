# Frameworks

Reusable structures for thinking and solving problems.

Frameworks answer questions such as:

> **“How can I approach this class of problem systematically?”**

Unlike guidelines, frameworks are more structured. They may define steps, decision points, inputs, outputs, trade-offs, or checklists.

Possible topics include:

- AI-assisted development workflows
- problem decomposition
- root-cause analysis
- architecture evaluation
- decision making
- software design and trade-off analysis
- learning and experimentation loops
- reasoning and investigation methods

Frameworks should be treated as tools, not dogma. A framework that repeatedly fails in practice should be refined or retired.
