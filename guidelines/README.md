# Guidelines

Practical rules for how I work.

Guidelines answer questions such as:

> **“When I face this kind of situation, what principles should guide my next action?”**

This area is intended for concise, actionable guidance rather than long theoretical explanations.

Possible topics include:

- AI-assisted programming
- working with coding agents
- prompt and context management
- debugging and investigation
- code review
- safe use of AI-generated code
- when to use or not use AI
- engineering habits and heuristics

Guidelines may be challenged and revised as new evidence or experience appears.

A guideline is considered useful when it changes behavior, not merely when it sounds reasonable.
